# Airline Flight Performance Analysis ✈️

## Project Overview

This project focuses on analyzing airline flight performance using Power BI. The goal is to explore flight delays, cancellations, airline performance, and operational patterns through an interactive dashboard.

The dashboard provides insights into flight operations and helps identify performance differences between airlines, cities, and days of the week.

## Objectives

- Analyze total flight volume and flight status distribution.
- Identify airlines with the highest delay rates.
- Compare average departure delays across airlines.
- Analyze flight distribution across different cities.
- Investigate flight cancellation patterns.
- Explore daily trends in flight delays and cancellations.

## Tools & Technologies

- **Power BI Desktop:** Dashboard development and data visualization.
- **DAX:** Creating calculated measures and KPIs.
- **Power Query:** Data preparation and transformation.

## Dashboard Features

### 1. Flight Overview
- Total number of flights.
- Delayed flights.
- Cancelled flights.
- On-time, delayed, and cancelled flight percentages.

### 2. Airline Performance Analysis
- Percentage of delayed flights by airline.
- Identification of the worst-performing airlines based on average departure delay.
- Comparison of airline performance.

### 3. City Analysis
- Total flights by city.
- Comparison of flight volumes across cities.

### 4. Cancellation Analysis
- Cancellation distribution by reason.
- Cancellation rate by day of the week.

### 5. Delay Analysis
- Average departure delay.
- Comparison of flight delays across different categories.
